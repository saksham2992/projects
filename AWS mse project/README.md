# BlueDepths - Ocean Life & Marine Conservation Website

## Objective
A responsive website that raises awareness about marine biodiversity, ocean ecosystems, endangered marine species and conservation initiatives. Built for the Mid-Semester Examination (Web Dev & Cloud Foundation), problem statement 10.

## Features
- Responsive layout with a mobile hamburger menu
- Page that gets darker as you scroll, with a live depth gauge (0 to 4,000 m)
- Ocean ecosystems section (coral reefs, mangroves and seagrass, deep sea)
- Endangered species cards with filters by IUCN status
- Conservation actions section
- Ocean pledge form with validation that prints the submitted details on the page

## Technologies Used
- HTML5
- CSS3 (Grid, Flexbox, media queries)
- JavaScript (basic DOM manipulation and events)
- GitHub for source control, Vercel for hosting
